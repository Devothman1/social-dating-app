# SocialMatch - Social Dating App 🎉

A comprehensive social dating platform that combines the best features of Facebook and Tinder.

## ✨ Features

### 🔐 Authentication
- User registration and login
- JWT token-based authentication
- Profile management

### 👥 Social Features
- Create, edit, delete posts
- Like, comment, and share
- Friend request system
- Social feed

### 💕 Dating Features
- Tinder-like swipe interface
- Match detection
- User discovery with filters
- Super like functionality

### 💬 Real-time Chat
- One-on-one messaging
- Group chat support
- Message reactions
- Typing indicators

### 🔍 Search & Discovery
- Advanced user search
- Filter by age, location, interests
- Friend suggestions

### 🔔 Notifications
- Real-time notifications
- Multiple notification types
- Notification preferences

## 🛠 Tech Stack

### Backend
- Node.js + Express.js
- MongoDB + Mongoose
- Socket.io (real-time)
- JWT authentication
- Multer (file uploads)

### Frontend
- React + TypeScript
- Styled Components
- React Router
- React Hook Form
- Axios (HTTP client)
- Socket.io Client

## 🚀 Quick Start

1. Clone the repository
2. Run `npm run install-all`
3. Configure `.env` files
4. Run `npm run dev`
